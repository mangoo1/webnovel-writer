# 卷摘要压缩 (Volume Compressor v1.0)

## 目标

- 将一卷（通常 50 章）的章节摘要压缩成单个卷摘要
- 保留关键事件、角色变化、未闭合伏笔
- 输出控制在 800-1200 字
- 为后续卷的写作提供历史上下文

## 使用方式

```bash
/webnovel-compress 1             # 压缩第1卷
/webnovel-compress 1-3           # 压缩第1-3卷
/webnovel-compress --all         # 压缩所有已完成卷
```

## 执行原则

1. 只压缩已完成的卷（所有章节摘要已生成）
2. 保留对后续剧情有影响的信息
3. 未闭合伏笔必须完整保留
4. 关键角色状态必须记录
5. 输出到 `.webnovel/summaries/vol{NN}.md`

## 引用加载

- 必读：`${OPENCODE_PLUGIN_ROOT}/references/summary-schema.md`（格式定义）

## 输出位置

```
{project_root}/.webnovel/summaries/vol{NN}.md
```

## 执行流程

### Step 1: 确定卷范围

```bash
# 从 state.json 读取卷规划
python "${OPENCODE_PLUGIN_ROOT}/../scripts/webnovel.py" \
  --project-root "{project_root}" \
  state show | grep -A 50 "volumes_planned"

# 确定卷的章节范围
# 第1卷: 0001-0050
# 第2卷: 0051-0100
# ...
```

### Step 2: 读取该卷所有章节摘要

```bash
# 列出该卷的所有摘要文件
ls "{project_root}/.webnovel/summaries/ch00{01..50}.md"

# 逐个读取
for i in {01..50}; do
  cat "{project_root}/.webnovel/summaries/ch00${i}.md"
done
```

### Step 3: 提取关键信息

从所有章节摘要中提取：

#### 3.1 主线事件（保留 5-8 个）

筛选标准：
- 改变主角命运的事件
- 引入重要角色的事件
- 重大转折点
- 伏笔埋设/回收节点

#### 3.2 角色状态变化

追踪主要角色的：
- 实力变化
- 位置变化
- 关系变化
- 状态变化（存活/失踪/死亡）

#### 3.3 未闭合伏笔

汇总所有：
- [新增] 且未标记 [回收] 的伏笔
- 记录埋设章节和紧急度

#### 3.4 世界观扩展

新增的：
- 地点
- 势力
- 设定/规则

### Step 4: 生成卷摘要

#### 4.1 YAML Frontmatter

```yaml
---
volume: {NN}
title: "{卷名}"
chapters: "{start}-{end}"
total_words: {总字数}
main_events: {主要事件数}
active_foreshadowing: {活跃伏笔数}
generated_at: "{生成时间}"
---
```

#### 4.2 正文部分

```markdown
## 卷概要

{一段话概括本卷主线，100-150字}

## 主线进展

1. [Ch{XX}-{YY}] {阶段1概述}
2. [Ch{XX}-{YY}] {阶段2概述}
3. [Ch{XX}-{YY}] {阶段3概述}
4. [Ch{XX}-{YY}] {阶段4概述}
5. [Ch{XX}-{YY}] {阶段5概述}

## 关键角色状态（卷末）

| 角色 | 实力 | 位置 | 状态 |
|------|------|------|------|
| {主角} | {境界} | {地点} | {状态} |
| {重要配角1} | {境界} | {地点} | {状态} |
| {重要配角2} | {境界} | {地点} | {状态} |

## 未闭合伏笔（需后续回收）

| 伏笔 | 埋设章节 | 紧急度 | 预计回收 |
|------|----------|--------|----------|
| {伏笔1} | Ch{XX} | {N} | 第{X}卷 |
| {伏笔2} | Ch{XX} | {N} | 第{X}卷 |

## 关系网络（卷末快照）

```
{主角} ──{关系}── {角色A}
  │
  ├──{关系}── {角色B}
  │
  └──{关系}── {角色C}
```

## 世界观扩展

- 新地点：{地点列表}
- 新势力：{势力列表}
- 新设定：{设定列表}
```

### Step 5: 写入文件

```bash
# 确保目录存在
mkdir -p "{project_root}/.webnovel/summaries"

# 写入卷摘要
# 文件名格式：vol{NN}.md，如 vol01.md
```

## 压缩策略

### 信息保留优先级

1. **必须保留**
   - 未闭合伏笔（100% 保留）
   - 主角状态变化
   - 重大转折事件
   - 新引入的重要角色

2. **选择性保留**
   - 配角状态变化（只保留关键角色）
   - 次要事件（合并或省略）
   - 情绪变化（只保留关键节点）

3. **可以省略**
   - 已回收的伏笔
   - 过渡性场景
   - 重复的情绪描写
   - 已离场的次要角色

### 字数控制

| 部分 | 目标字数 |
|------|----------|
| 卷概要 | 100-150 |
| 主线进展 | 200-300 |
| 角色状态表 | 150-200 |
| 未闭合伏笔表 | 100-200 |
| 关系网络 | 100-150 |
| 世界观扩展 | 100-150 |
| **总计** | **800-1200** |

## 批量压缩

批量压缩多卷时：
1. 按卷序号顺序处理
2. 检查每卷的章节摘要是否完整
3. 缺失摘要时报告并跳过该卷
4. 完成后输出统计
